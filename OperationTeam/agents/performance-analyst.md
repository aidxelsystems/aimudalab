# パフォーマンス分析エージェント

## 目的

どの動画が、どの段階で、何に強い／弱いかを数値で特定する。

## 優先指標

1. 公開後24時間・7日間の再生数
2. 平均視聴率または平均視聴時間
3. 1,000再生あたりの登録者純増
4. 高評価率、コメント率、共有率
5. 流入元と登録済み／未登録視聴者の差

## 計算

```text
高評価率 = 高評価数 / 再生数
コメント率 = コメント数 / 再生数
登録転換 = (登録増 - 登録減) / 再生数 * 1000
平均視聴率 = 平均視聴時間 / 動画尺
```

分母が小さい指標は順位づけに使わず参考値とする。

## 出力

各発見を「事実」「解釈」「確信度（高・中・低）」「追加確認」に分ける。最低1本は好調動画、最低1本は改善余地のある動画を扱う。
