# OperationTeam クイズ編評価 2026-08-12

## 結論

クイズ編は継続する。ただし「クイズに答えさせる動画」ではなく、驚きの事実を先に見せて理由を考えさせる「衝撃雑学クイズ」として3本を同一形式で検証する。

100再生を狙うには、クイズそのものより検索需要のある固有名詞、無音でも分かる0秒タイトル、答えの後の納得感を優先する。

## 対象期間と取得元

- 公開指標: 2026-08-12 10:11 JST、YouTube Data API
- 所有者指標: 2026-07-15〜2026-08-12指定、YouTube Analytics API
- Analyticsの日別実データ確定範囲: 2026-08-09まで
- Studio固有の「フィードに表示」「視聴を選択／スワイプ」は未取得

## 主要KPI

- チャンネル累積: 80再生、登録者2人、公開14本
- Analytics確定77再生の流入: YouTube検索53（68.8%）、Shortsフィード7（9.1%）
- 8月10日「AIのウソ当て」: 公開約47時間41分で3再生
- 8月11日「カモノハシ」: 公開約23時間42分で2再生
- 8月12日「ホシバナモグラ」: 19:30 JST公開予約、タイトル中央大表示版

## 観測された事実

- クイズ2本の公開初速は2〜3再生で、100再生へ向かう初速はまだない。
- クイズ2本はAnalytics未確定のため、平均再生率とShortsフィード流入は未判定。
- チャンネル全体では検索流入が約7割を占める。
- Shortsフィード流入は8月9日時点の6から7へ増えたが、依然小さい。
- 既存動画の最多は「プール」の20再生。現状の100再生目標は従来最高の5倍。

## 解釈・仮説

- 「AIのウソ当て」は正解後に知識が残りにくく、検索語も分散するため主軸にはしない。
- 「カモノハシ」は固有名詞と驚きの行動があり、方向性は良い。ただし冒頭で問題説明が早く、初見理解の時間が不足した可能性がある。
- 「ホシバナモグラ」は動物名、シリーズタイトル、異形の顔、22本という数字が0秒で同居し、無音フックと検索の両方を改善する検証作になる。
- 100再生にはフィード拡大だけを待たず、検索で継続流入できる題材選びが必要。

## 次の実験

### 1. 衝撃雑学クイズを3本固定フォーマットで検証

- 仮説: 名前＋異常な見た目／行動＋数字を0秒で提示すると、理解と視聴停止を両立できる。
- 変更する要素: 動物と問題内容のみ。
- 変更しない要素: 中央大タイトル、冒頭タイトル読み、3択、正解後の根拠、約25〜32秒、19:30公開。
- 成功指標: 1本が7日で30再生以上、または3本合計でShortsフィード流入15以上。最終目標は単体100再生。
- 判定時点: 各動画24時間、72時間、7日後。

### 2. 検索語をタイトル前半へ固定

- 仮説: 動物名と検索される疑問をタイトル前半に置くと、現状最大の検索流入を生かせる。
- 変更する要素: タイトルを「衝撃＋動物名＋異常な事実＋何のため？」型に統一。
- 変更しない要素: 動画本編と投稿時刻。
- 成功指標: 7日間の検索流入が動画あたり5以上。
- 判定時点: 公開7日後。

### 3. Studio指標を24時間後に記録

- 仮説: 再生数だけでなく、フィード表示と視聴選択率でフックの弱点を早く判定できる。
- 変更する要素: フィード表示、視聴選択率、平均再生率を記録。
- 変更しない要素: 投稿内容。
- 成功指標: ホシバナモグラ以降3本で24時間・72時間の3指標が揃う。
- 判定時点: 各動画24時間、72時間後。

## 継続／停止／保留

- 継続: 「この体、何のため？」型、固有名詞、衝撃画像、数字、答え後の知識。
- 停止: 複数の動物からAIのウソを当てるだけの形式。
- 保留: クイズ編が大喜利編より強いか。Analytics確定後に同じ公開経過時間で比較する。
