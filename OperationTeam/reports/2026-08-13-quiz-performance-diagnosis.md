# OperationTeam クイズ編緊急診断 2026-08-13

## 結論

クイズ編は現時点で100再生への兆候がなく、初速は明確に弱い。ただし主因は「見た人が離脱した」より前の、表示・配信母数不足と考えるのが妥当。

同じ形式を無条件で量産せず、ホシバナモグラとラッコの72時間値、およびYouTube Studioの`フィードに表示`と`視聴を選択した割合`を取得してから次のクイズ形式を決める。

## 対象期間と取得元

- 公開値: 2026-08-13 21:49 JST、YouTube Data API
- Analytics: 2026-07-16〜2026-08-13指定、YouTube Analytics API
- Analytics実データの最終日: 2026-08-10
- 欠損: Studio固有の`フィードに表示`、`視聴を選択／スワイプ`、8月11日以降の確定Analytics

## 観測された事実

- AIのウソ当ての確定1再生は検索ではなくShortsフィード由来。
- その1再生の平均再生率は89.59%で、見た人が即離脱した証拠はない。
- SEOを強めたカモノハシとホシバナモグラにも、公開値上の検索流入増加はまだ表れていない。
- 高評価、コメント、共有はクイズ編で0。
- Analytics反映が8月10日までのため、カモノハシ以降の維持率は判断不能。

## 解釈・仮説

### 1. 最優先: 配信母数不足

フィードへ何回表示され、何人がスワイプしたかが不明。再生0〜3では、題材や構成の優劣を統計的に比較できない。

### 2. SEO単独では初速を作れていない

検索はタイトル一致だけでなく、検索結果でクリックされ視聴された実績やチャンネルの信頼性も競争要因になる。立ち上げ直後の小規模チャンネルでは、検索語を入れただけで上位表示されるとは限らない。

### 3. チャンネルの視聴者像が未形成

大喜利と動物クイズが混在し、登録者2人、累積85再生のため、YouTubeが「誰に薦める動画か」を学習できる視聴履歴が少ない可能性がある。

### 4. クイズの回答待ちが弱点の可能性

直近作は正解までの待ち時間がある。フィード表示後の視聴選択率や離脱曲線が悪ければ、次は答え先出しの15〜20秒雑学へ変更する。ただし現段階ではデータ未反映のため仮説。

## 判定表

以下はYouTube公式基準ではなく、当チャンネルの次回実験用ゲート。

| 72時間の状態 | 診断 | 次の変更 |
|---|---|---|
| フィード表示20未満 | 配信テスト不足 | 題材をさらに広くし、真正な外部流入で初期視聴者を作る |
| 表示50以上・視聴選択50%未満 | 0秒フック不足 | 問題文を減らし、異常な事実を最初に最大表示 |
| 視聴選択65%以上・平均再生率70%未満 | 中盤離脱 | 3択を廃止し、答え先出し15〜20秒へ短縮 |
| 視聴選択65%以上・平均再生率85%以上 | 内容は有望 | 同型を3本継続し、題材だけ変更 |

## 次の運用

1. ラッコは削除・再投稿せず、72時間まで観測する。
2. ホシバナモグラとラッコについて、Studioから`フィードに表示`、`視聴を選択した割合`、`平均再生率`を24時間・72時間で記録する。
3. 8月14日の大喜利を対照作として残し、同じ公開後24時間で比較する。
4. 次のクイズ制作は上記の表示数が判明するまで保留。作る場合も、同型の3択量産ではなく答え先出し型を比較候補とする。

## 継続／停止／保留

- 継続: 公開済みクイズの観測、検索語と内容の一致、0秒の大文字。
- 停止: SEOだけを追加して同型クイズを連続量産すること。
- 保留: クイズ形式そのものの撤退。維持率とフィード表示が揃うまでは判断しない。
