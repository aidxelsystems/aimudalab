# AIのムダづかい YouTube成長分析

作成日: 2026-08-28 JST

## 結論

**再生数は小さいながら、伸び始めた兆候がある。** 同じ5日間で比べると再生数は28回から42回へ50%増加した。ただし、増加の中心はYouTube検索であり、Shortsフィードの配信拡大はまだ確認できない。

現在の有力な勝ち筋は、`検索される固有名詞` と `一目で分かる異常映像` を組み合わせ、30秒前後で `驚き → 仕組み → ツッコミ` まで進む形式である。

## 対象期間

- 公開指標: 2026-08-28 12:40 JST収集時点
- Analytics比較期間: 2026-08-16〜20 と 2026-08-21〜25（各5日）
- Analytics全体期間: 2026-07-31〜2026-08-28

## 取得元と欠損

- YouTube Data API: チャンネル、公開動画、累積再生、高評価、コメント
- YouTube Analytics API: 日別、動画別、平均視聴、流入元、デバイス
- Analyticsの日別行は2026-08-25まで。直近2〜3日は報告遅延がある。
- `subscribedStatus` はYouTube側の500エラーで取得できなかった。
- 「視聴を選択／スワイプ」と冒頭3秒残存率はAPIで取得できない。
- 実際のYouTube検索語はAPIクエリ非対応。確認にはYouTube StudioのCSVが必要。
- 公開チャンネル総再生207回と、公開動画別累積合計213回に6回の差がある。YouTube側の集計時差として両方を記録する。

公開データの長めの傾向でも、2026-08-21 00:40 JSTの130回から2026-08-28 12:40 JSTの207回へ、約7.5日で77回増加した。約10.3回／日であり、8月12日〜18日の約6.5回／日より高い。ただし両期間で投稿本数と動画年齢が完全には一致しないため、補助的な兆候として扱う。

## 流入元

全期間のAnalytics再生168回の内訳:

- YouTube検索: 114回（67.9%）
- 外部URL: 37回（22.0%）
- Shorts: 11回（6.5%）
- チャンネルページ: 6回（3.6%）

8月26日取得値から8月28日取得値までの差分参考:

- Analytics再生: +30
- YouTube検索: +20
- 外部URL: +9
- Shorts: +1

データ修正が入る可能性はあるが、直近増加の約3分の2が検索、Shortsは約3%に留まる。外部URLには共有だけでなく、投稿後の確認アクセスが含まれる可能性があるため、自然拡散とは断定しない。

## 伸びた動画

### 1. うずめ飯

- 公開累積: 17回
- Analytics集計: 13回
- YouTube検索: 11回
- 外部URL: 2回
- 平均視聴: 16秒／27秒、62.8%

**事実:** 直近動画で最多再生。Analytics再生の85%が検索だった。

**解釈:** `日本五大名飯`、`具がない`、`うずめ飯` という検索可能な固有名詞と矛盾が入口になった可能性が高い。視聴率は突出していないため、主因は維持率より発見性と考えるのが妥当。

### 2. 地獄炊き

- 公開累積／Analytics: 9回
- 平均視聴: 32秒／34秒、96.8%
- 流入: 検索4、外部4、Shorts 1

**事実:** 小標本ながら、直近作品で最も強い視聴維持。直近グルメでShorts流入が1回確認できた唯一の動画。

**解釈:** `地獄へ落とす` という強い緊張から、温かいうどんとツッコミへ戻す構成が最後まで見る理由になった可能性がある。

### 3. 過冷却

- 公開17.7時間時点: 6回
- Analyticsは報告遅延により未反映

**事実:** ゼリーフライは22.7時間で3回、たまごふわふわは29.7時間で3回、半ごろしは24.8時間で4回だった。過冷却は現時点で、それらより初速が強い。

**解釈:** `叩いた瞬間に凍る` という動きのある結果先出しが、静的な料理紹介より理解を速めた可能性がある。ただし流入元と維持率が未確定なため、確信度は中以下。

## 改善余地のある動画

### ハッブル宇宙望遠鏡

- 公開累積: 7回
- Analytics: 4回
- 平均視聴: 16秒／32秒、52.2%
- 流入: 検索2、外部2

題材と物語は深いが、`ピンボケ → 原因 → 修理` の理解に時間がかかり、瞬間的な状態変化を見せる科学実験よりShorts上の入口が弱かった可能性がある。内容の価値ではなく、初見理解速度の問題という仮説である。

### 長尺AI大喜利

直近の温泉旅館は平均視聴率41.3%（26秒／64秒）。60〜78秒の大喜利は、現在の流入規模では各ボケまで到達する前に離脱されやすい兆候がある。シリーズ自体を停止せず、現Phaseでは短尺へ戻すか保留する。

## 観測された事実

- 同じ5日間で再生数は50%増加した。
- その一方、チャンネル全体の平均視聴率は73.9%から61.6%へ低下した。
- 検索が全期間再生の67.9%を占める。
- Shortsフィードは全期間11回、6.5%に留まる。
- 高評価、コメント、共有、登録純増は直近比較期間で0。
- 検索に強い動画と、視聴維持に強い動画が別である。

## 解釈・仮説

1. **成長は始まっているが、配信面の突破ではなく検索面の改善である。** 確信度: 中。
2. **固有名詞＋矛盾のタイトルが検索流入を作る。** うずめ飯が支持。確信度: 中。
3. **動く結果先出し＋緊張と緩和が視聴維持を作る。** 地獄炊きと過冷却が支持。確信度: 低〜中。
4. **再生後の反応と登録転換が不足しており、ファン化は未発生。** 確信度: 高。

## 次週の実験（最大3件）

### 実験1｜予約済み科学5本を同じ型のテスト群として測る

仮説: `結果先出し → 固有名詞 → 仕組み → 意外な用途 → ツッコミ` は、検索とShortsの両方へ届く。

変更する要素: 題材だけ。

変更しない要素: 25〜35秒、中央大文字、AI表示、一次資料、最後のツッコミ、19時公開。

成功指標: 24時間10回以上、72時間15回以上、Shorts流入2回以上。100回はストレッチ目標として別記録する。

判定時点: 各動画の24時間後・72時間後・7日後。

### 実験2｜地獄炊き型の緊張を冒頭1秒へ移植

仮説: 危険に見える一文と決定映像を0秒から同時提示すると平均視聴率が上がる。

変更する要素: 冒頭1秒の危険・矛盾の強度。

変更しない要素: 30秒前後、説明量、VOICEVOX、BGM音量、CTA。

成功指標: 20再生以上の時点で平均視聴率90%以上。20未満では順位づけせず兆候扱い。

判定時点: 72時間後と7日後。

### 実験3｜コメントCTAを回答しやすい一問へ絞る

仮説: `知っていましたか？` より、動画内容に直結する二択の方が最初のコメントを生みやすい。

変更する要素: 最後のCTA文だけ。

変更しない要素: 題材、尺、映像、タイトル、公開時刻。

成功指標: 次の5本のどれかでコメント1件、または高評価1件。再生数は副指標。

判定時点: 各動画の72時間後。

具体的な次題材は、予約済みの磁性流体、プリンス・ルパートの滴、ガリウム、マジックサンド、エアロゲルの24時間データを見てから選ぶ。

## 継続／停止／保留

- 継続: 25〜35秒の科学・グルメ事実エンタメ、検索可能な固有名詞、緊張と緩和、一次資料。
- 一時停止: 60秒超のAI大喜利。チャンネルを否定せず、Shorts配信面が育つまで制作優先度を下げる。
- 保留: 科学とグルメの最終的な勝敗。次の予約5本を同じ経過時間で比較する。
