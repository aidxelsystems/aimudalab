# AIのムダ遣いちゃんねる BusinessTeam

YouTubeの運用実績と制作資産を、広告収益以外も含む持続的なビジネスへ接続するサブエージェントチームです。

現在は `VALIDATE`（商品検証）モードです。AIグルメ3本の完成品質と縦型動画市場の需要を確認できたため、外部営業の前にサービス範囲、制作工数、商用ライセンス、価格仮説、ポートフォリオを整えます。

## チーム

- `agents/business-manager.md` — 事業統括と承認ゲート
- `agents/revenue-strategist.md` — 収益モデルと採算
- `agents/opportunity-researcher.md` — 顧客・市場・協業機会の調査
- `agents/offer-designer.md` — サービスと提案物の設計
- `agents/risk-reviewer.md` — AI、広告、権利、事実性の監査

詳しいルールは `AGENTS.md` にあります。

## 入力

- `../OperationTeam/reports/`: 再生、流入、視聴維持、登録転換
- `../PlanningTeam/output/` と `../PlanningTeam/research/`: 市場と企画仮説
- `../ProductionTeam/` と `../out/`: 制作工程、完成作品、制作再現性
- `../CHANNEL_VISION.md`: チャンネルの長期方針

## 出力

- `reports/`: 事業化準備度と次の判定
- `research/`: 顧客、市場、競合、価格、制度の根拠付き調査
- `handoffs/`: ユーザー承認後の案件・提案準備書
- `templates/`: 判定と案件準備の共通書式
- `offers/`: 将来の商品案、価格仮説、販売前の再判定条件

## 現在の考え方

AIグルメシリーズは、視聴実績がまだ出ていないためスポンサー媒体として売りません。一方、企画、AI映像、ナレーション、字幕、BGM、出典、投稿準備までを一貫して作れる点は、地域・食品事業者向け縦型動画の制作サンプルになり得ます。

チャンネルの広告媒体価値は、2026年8月17日〜19日公開予定のAIグルメ3本について、同じ公開後経過時間のデータがそろってから判断します。一方、動画制作受託は再生数と分けて検証します。

## 禁止事項

BusinessTeamは、ユーザーの明示承認なしに営業メール、SNSのDM、案件応募、見積送付、契約、購入、課金を行いません。
