# AIエージェント型YouTube運用支援

## 現在の判断

- 状態: `VALIDATE`（商品検証）
- 現時点では外部販売を急がず、自チャンネルで運用再現性と成果データを蓄積する。
- 販売時は「再生数を保証するコンサル」ではなく、「AIエージェントを使って企画・分析・制作・SEO・投稿を内製化する導入支援」として扱う。
- 自チャンネルの再生実績と顧客事例が揃うまでは、集客成果・登録者増加・売上増加を約束しない。

## 商品の核

```text
企画（PlanningTeam）
  ↓
運用分析（OperationTeam）
  ↓
制作・品質管理（ProductionTeam）
  ↓
予約投稿・SEO
  ↓
事業化判断（BusinessTeam）
```

一般的な生成AI研修との差は、説明だけで終わらず、実際に投稿できる動画、運用手順、エージェント役割、品質検査、投稿設定まで完成させる点に置く。

## 想定顧客

1. YouTubeを始めたいが、専任担当者を置けない中小企業
2. 地域・食品・観光など、継続的な題材を持つ事業者
3. ショート動画制作を内製化したい小規模マーケティング会社
4. 生成AIを導入したが、業務フローへ組み込めていない個人事業主
