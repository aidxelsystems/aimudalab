# 価格検討

表示価格は税別の仮説。外部への提示・確定にはユーザー承認が必要。

## 価格ラダー

| 商品 | 主な内容 | 価格仮説 |
|---|---|---:|
| 手順書・テンプレート | 汎用PDF、プロンプト、チェックリスト | 49,800〜79,800円 |
| 単発診断 | 事前確認、90分相談、改善レポート | 79,800〜120,000円 |
| パイロット導入 | 個別手順書、90分×2回、動画1本、2週間支援 | 初回3社 198,000円 |
| 標準導入 | 4週間伴走、運用設計、制作環境、研修 | 398,000〜598,000円 |
| 法人フル導入 | API、自動化、権限設計、複数担当者研修 | 800,000〜1,500,000円 |
| 継続支援 | 月次分析、改善会議、スキル更新 | 月額100,000〜300,000円 |

## 現時点の推奨

- 希望小売価格: 298,000円
- 初回3社のモニター価格: 198,000円
- 値引き条件: ヒアリング協力、実績掲載許諾、提供範囲固定、修正回数1回
- 値引きしない条件: 顧客別の大幅なシステム開発、複数チャンネル、複数SNS、現地撮影、無期限サポート

## 最低価格の計算

```text
最低価格 = 想定工数 × 目標時間単価
         + AI・生成・素材・クラウド費
         + 修正バッファ
         + 販売・管理・決済コスト
         + リスクバッファ
```

パイロット案件では、以下を必ず実測する。

- ヒアリング時間
- 手順書の個別調整時間
- エージェント・スキル設定時間
- 動画1本の企画、生成、編集、検査、投稿時間
- 打ち合わせ、質問対応、修正時間
- 有料ツール・生成クレジット

## 価格改定条件

- 3社完了かつ満足度を確認: モニター価格を終了
- 標準納期と平均工数を確定: 398,000円以上へ
- 顧客が自力で運用を継続できた事例: 498,000円以上を検討
- 問い合わせ・採用・売上等の事業成果を検証: 成果設計を含む上位プランを検討

## 契約で固定する項目

- 対象チャンネル数
- 動画本数
- 打ち合わせ回数
- 修正回数
- サポート期間
- 顧客が用意するアカウント・素材
- AI生成物、コード、手順書の利用範囲
- 再配布・転売の禁止
- 実績公開の可否
- 外部サービス料金と仕様変更への対応
