# 再検討ゲート

## 再確認する時期

次のいずれかを満たした時点で、BusinessTeamが商品化準備度と価格を再評価する。

1. 同一シリーズを6本以上公開し、各動画の公開後72時間データが揃った
2. 100再生以上の動画が3本できた
3. Shortsフィード表示、視聴選択率、平均視聴率を継続的に取得できた
4. 企画から投稿までの制作時間を10本分記録した
5. 外部事業者が本手順に関心を示し、具体的な課題をヒアリングできた

## パイロット販売の開始条件

- 完成動画10本以上を作例として提示できる
- 同じ品質で3本以上を連続制作できる
- 手順書とスキルが第三者でも実行可能な状態になっている
- 1本あたりの制作時間と生成費を説明できる
- OAuth、権限、AI表示、出典、著作権のチェックリストがある
- 提供範囲、修正回数、納期、サポート期間を固定できる

## 標準価格への移行条件

- 有料パイロット3社を完了
- 顧客満足度と改善点を記録
- 顧客が支援後も自力で1か月以上運用
- 導入前後の時間削減または投稿継続率を定量化
- 顧客許諾を得た事例を1件以上公開可能

## 成長支援を訴求できる条件

以下が揃うまでは「再生数を伸ばす」「集客できる」と約束しない。

- 同条件の投稿を一定本数比較したデータ
- Shortsフィード表示と視聴選択率の改善
- 平均視聴率だけでなく、高評価・共有・登録転換の改善
- 顧客チャンネルでの再現事例
- 外部要因と施策効果を分けた説明

## 次回BusinessTeam確認項目

| 項目 | 確認内容 |
|---|---|
| 作品証拠 | 見せられるシリーズと本数 |
| 需要証拠 | 問い合わせ、ヒアリング、検索需要 |
| 制作再現性 | 工数、品質、修正率、投稿エラー |
| 採算性 | 時間単価、生成費、サポート負担 |
| 信頼・安全性 | AI表示、出典、権限、契約範囲 |

## 現在の保留事項

- 外部営業と案件応募
- 顧客への価格提示
- 成果保証を含む販売表現
- 手順書の再配布・ライセンス条件の確定
- 顧客認証情報を扱う実装方式
