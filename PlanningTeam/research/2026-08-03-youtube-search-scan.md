# YouTube検索市場スキャン 2026-08-03

対象: 2026年8月5日投稿候補

## 調査方法

YouTube Data API `search.list` を日本・日本語条件で実行し、検索上位の題材と検索意図を観測した。`pageInfo.totalResults` は部分一致を広く含むため需要規模の評価には使わず、上位タイトルの意図だけを判断材料とした。

## スイカ割り 夏休み

上位傾向:

- 家族・夏休みVlog
- スイカ割りへの挑戦、検証、対決
- 「ガチ」「独特すぎる」「とんでもない」など結果への好奇心

判断:

- エンタメ視聴意図が強く、「逃げるスイカ」という異常な結果と整合する。
- `スイカ割り` と `夏休み` をタイトル・概要欄冒頭に自然に置ける。
- 完全一致の「こんなスイカ割りは嫌だ」は既存例があるため、独自の事件「スイカが逃げる」をタイトル後半で区別する。

## ラジオ体操 夏休み

上位傾向:

- 実際のラジオ体操動画
- 地域行事・ニュース
- 毎日の運動、指導

判断:

- 検索需要はあるが、実演・情報目的が中心でコメディとの意図差が大きい。
- 検索クリック後の満足度を損なう可能性があるため、今回のSEO起点にはしない。

## 歯医者 おもしろ

上位傾向:

- 歯科あるあるShorts
- 医療情報
- 漫才・コント

判断:

- コメディ需要は存在するが情報目的も混在する。
- 完成動画が63.68秒の旧型で、今回検証したい15～20秒の一事件型と一致しない。
