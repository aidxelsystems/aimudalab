# AIグルメ「緊張と緩和」企画候補

作成日: 2026-08-19  
目的: 冒頭の緊張で指を止め、料理の正体を知った安心とツッコミで最後まで見てもらう

## 結論

次作の第一候補は、徳島県那賀町の郷土料理「半ごろし」とする。

強い言葉を表示するだけではなく、次の感情曲線を映像内で完結できる。

```text
何をするの？ → 本当に米をつぶす → 料理名だったのか → 名前が怖すぎる
```

## 第一候補：徳島「半ごろし」

### フック

フレーム0から中央に大きく表示:

```text
この米、
半ごろしにします
```

音声:

```text
今から、この米を半ごろしにします。
```

画:

- 湯気の立つもち米へ、すりこぎがゆっくり近づく超接写。
- 黒背景にせず、最初から米と道具を見せて「料理の話」と分かるようにする。
- 血、刃物、人物の恐怖表現は使わない。

### 25〜28秒の感情設計

1. **0〜3秒・緊張**  
   `この米、半ごろしにします。`
2. **3〜8秒・実行**  
   米粒を少し残すように、すりこぎで半分だけつぶす。
3. **8〜13秒・安心**  
   `正体は、徳島県那賀町のおはぎのような郷土料理。`
4. **13〜18秒・納得**  
   半分だけすりつぶすため、名前が「半ごろし」になった。
5. **18〜22秒・再緊張**  
   `では、全部つぶすと？`
6. **22〜25秒・二段オチ**  
   `みなごろし。`
7. **25〜28秒・ツッコミ＋CTA**  
   `名前が物騒すぎる、おはぎかい！`  
   `チャンネル登録もよろしく`

### Google Flowの2カット

#### 1カット目：半分だけつぶす

- 炊きたてのもち米とうるち米を、木のすりこぎでゆっくりつぶす。
- 米粒が一部残っていることが分かるマクロ撮影。
- 湯気、粘り、柔らかな照りを強調する。

#### 2カット目：甘い正体

- つぶした米であんを包み、きな粉またはヨモギのおはぎに仕上げる。
- 半分に割り、あんと粒の残った生地を見せる。
- 最後は和菓子広告のような食欲カットにする。

### タイトル案

```text
この米、半ごろしにします…徳島の郷土料理が物騒すぎる #Shorts
```

### 注意点

- 公式表記に合わせ、タイトルと字幕は漢字の「半殺し」ではなく「半ごろし」を使う。
- 冒頭から米を映し、暴力動画と誤認される見せ方を避ける。
- 刺激語の強さを検証する回なので、他の構成要素は既存のAIグルメ型を維持する。

## 第二候補：別府「地獄蒸し」

### フックとオチ

```text
フック：この食材、地獄に入れます
回収：正体は98度の温泉噴気を使う、江戸時代からの調理法
オチ：地獄なのに、いちばん健康的かい！
```

### 強み

- 大量の蒸気、釜を開ける瞬間、魚介や野菜の完成形が映像向き。
- 「地獄」という緊張を、おいしくヘルシーな料理へ反転できる。
- 別府、温泉、地獄蒸しという検索語を自然に含められる。

### 弱み

- オチが想像しやすく、言葉の意外性は「半ごろし」より弱い。

## 第三候補：秋田・男鹿「石焼料理」

### フックとオチ

```text
フック：木の桶に、真っ赤な石を入れます
回収：熱した石で魚介の汁を一気に煮る漁師料理
オチ：鍋の中にコンロを入れるんかい！
```

### 強み

- 真っ赤な石、沸き上がる汁、激しい湯気で三候補中もっとも映像が強い。
- 古い漁師の知恵という「なるほど」も入る。
- 視覚的な緊張から、おいしそうな魚介汁への緩和が明確。

### 弱み

- AIが石、木桶、沸騰を不自然に生成する可能性があり、事実映像に見せるには検品が必要。

## 今回の検証仮説

`衝撃`のような抽象語より、`半ごろしにします`のように「このあと何が起きるか」を具体的に予告する方が、視聴者は結末を確認したくなる。

今回変える要素:

- フックを「矛盾」から「安全な危機予告」へ変更
- 中盤に再緊張の質問を一度入れる
- オチを知識の説明ではなく、感情が緩むツッコミにする

変えない要素:

- 約25〜28秒
- 2本のAI料理映像
- 料理名、地域、由来、食欲カット、ツッコミ、CTA
- VOICEVOX、BGM、字幕の基本デザイン
- AI映像の免責は概要欄へ記載
