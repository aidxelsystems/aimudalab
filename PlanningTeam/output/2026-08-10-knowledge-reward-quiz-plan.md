# 「正解後に得する」知識クイズ再設計案 2026-08-10

## 結論

次の中心企画は、`1匹だけAIのウソ` から `この体、何のため？` へ進化させる。

三択は視聴の入口に留め、正解発表後を本編にする。視聴者が最後に持ち帰るものを、単なる正誤ではなく「変な見た目には合理的な理由がある」という納得に変える。

推奨シリーズ名：`この体、何のため？｜AI動物研究所`

番組の約束：`20秒後、変な見た目が天才に見える。`

## 現行形式の課題仮説

- `どれがAIか` の答えは、その動画だけで完結し、日常で話したくなる知識として残りにくい。
- 3匹へ注意が分散し、1匹の特徴と理由を深く記憶しにくい。
- AI創作が中心だと、実在情報まで疑って見る負荷が生まれる。
- 正解発表がゴールになり、その後に再視聴・共有したくなる報酬が少ない。

公開済み動画の24時間データが揃う前なので、以上は数値による断定ではなく企画構造上の仮説とする。

## 新しい感情設計

`変な顔で驚く → 理由を予想する → 正解に驚く → 仕組みに納得する → 誰かに話したくなる`

## 19〜22秒の基本構成

| 時間 | 内容 | 役割 |
|---|---|---|
| 0〜1.5秒 | 顔のどアップ＋具体的な疑問 | スクロール停止 |
| 1.5〜5秒 | A・B・Cを同時提示 | 自分で予想 |
| 5〜6秒 | `答えは…`。長いカウントはしない | 緊張 |
| 6〜9秒 | 正解を即表示 | クイズ報酬 |
| 9〜15秒 | 仕組みを2段階の絵で説明 | 知識報酬 |
| 15〜19秒 | AIで能力の世界を誇張可視化 | エンタメ報酬 |
| 19〜22秒 | 1行要約＋冒頭へ戻る | 記憶・ループ |

## 第1作案：カモノハシ

### 冒頭1秒の約束

`目・耳・鼻を閉じて狩る。どうやって？`

0秒から水中のカモノハシの顔を大きく見せる。文字は上側。暗い水中に、くちばしへ向かう微弱な電気の波をAIイメージとして描く。

### 三択

- A：超音波を出す
- B：くちばしで電気を感じる
- C：水の味で追跡する

### 正解と知識報酬

正解はB。

カモノハシは水中で餌を探す際、目・耳・鼻を閉じる。くちばしには圧力を感じる受容器と電気受容器があり、獲物を探す主要な感覚器官になる。

画面では次の2段階で説明する。

1. エビなどが動く。
2. その動きに伴う微弱な電気を、くちばしが捉える。

断定しすぎないため、`正確な使い方には未解明な点もある` は概要欄へ記載する。

出典：Australian Museum
https://australian.museum/learn/animals/mammals/platypus/

### AIエンタメの一枚

水中を暗くし、獲物の動きから細い電気の足跡が伸び、カモノハシのくちばしだけがレーダーのように反応する世界を可視化する。

表示：`AIイメージ：電気の足あとを読む世界`

最後の一言：`このくちばし、電気を読む“手”だった。`

### タイトル案

`カモノハシは目を閉じて狩る｜どうやって？ #Shorts`

## 次の題材候補

1. ウォンバット：`なぜ四角いうんちになる？`ではなく、証明しやすい`どうやって四角くなる？`
2. トナカイ：`冬になると目の色が変わるのはなぜ？`
3. ヤモリ：`なぜ壁から落ちない？`
4. キーウィ：`鳥なのに鼻の穴がくちばしの先なのはなぜ？`

すべて「奇妙な外見・行動 → 三択 → 機能の説明 → AI可視化」に統一する。

## 市場・公式シグナル

- 2026-08-09のYouTube Data API観測では、面白動物の日本語短尺に663万再生、74万再生の上位例があり、題材需要のシグナルは強い。ただし自チャンネルでの成功を保証するものではない。
- YouTube公式は、冒頭で価値の約束を直ちに実現し、その後も好奇心と期待を維持して価値を届けることを推奨している。
  - https://support.google.com/youtube/answer/16559650
- Shortsでは `Shown in feed`、`How many chose to view`、視聴維持、反応を同形式で比較する。
  - https://support.google.com/youtube/answer/12942217

## 今回変える1要素

`正解の報酬`を「架空動物の特定」から「実在動物の体の理由と仕組み」へ変える。

## 変えない要素

- 20秒前後
- 0秒から強い顔
- 上側テロップ
- A・B・Cの参加要素
- VOICEVOX、効果音、縦型Remotion
- 最後のチャンネル登録CTA

## 14枚の画の方向

1. 水中の顔どアップ
2. 閉じる目
3. 閉じる耳の溝
4. 閉じる鼻孔
5. 三択フリップ
6. Aの超音波イメージ
7. Bの電気イメージ
8. Cの水味イメージ
9. 正解B
10. 動くエビ
11. 微弱な電気の発生
12. くちばしの受容器
13. 電気の足あとを読むAI可視化
14. 1行要約＋冒頭へのループ

## 避ける表現

- `電気が見える` と事実として断定しない。可視化には `AIイメージ` を付ける。
- `完全なレーダー`、`何でも感知できる`など能力を誇張しない。
- 出典のない数値を足さない。
- 正解まで10秒以上引っ張らない。

## 成功判定

### 公開24時間

- 現行の変な動物クイズと同じ公開後経過時間で比較する。
- Shortsフィード表示の有無。
- `視聴を選択`率が現行動画以上。
- 正解発表後に当たる動画後半の維持が、現行動画より改善。

### 公開7日

- 平均再生率、コメント率、高評価率のうち2指標以上が現行動画を上回る。
- 検索語に動物名または疑問語が現れる兆候がある。
- 次の題材を求めるコメント、知識への反応が1件以上ある。
