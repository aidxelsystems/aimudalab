取得元: YouTube Data API / YouTube Analytics API  
取得日時: 2026-08-21 00:40 JSTごろ

## 結論

飯シリーズへ一本化はしない。ただし終了もしない。

今週は「半ごろし」で、グルメ映像に強い緊張と緩和を加える実験を完了する。来週は同じ動画編集形式を維持したまま、題材だけを非グルメの「天才の残念ヒストリー」へ変更する。以後は、当面 `グルメ1本＋新シリーズ1〜2本` を1週間の基本配分とする。

- 小標本のため、動画形式の優位性は現時点では仮説である。

## 方針の理由

### グルメを残す理由

- 調理、湯気、断面、発見など、AI動画の動きを自然に活かせる。
- 地域名、料理名、由来があり、検索と知識欲の入口を作りやすい。
- 4本だけで停止すると、フック改善前後を比較できない。

### グルメだけにしない理由

- 現在の絶対再生数では、グルメをチャンネルの勝ち筋と認定できない。
- 「AI×エンタメ」のチャンネルを、郷土料理解説だけに狭める段階ではない。
- 映像が効いたのか、料理テーマが効いたのかを切り分ける必要がある。

## 来週の新シリーズ

仮タイトル:

```text
天才の残念ヒストリー
```

基本構成:

```text
0〜3秒   大事故・失敗・消失を具体的に予告
3〜8秒   天才、建物、発明の価値を本気で紹介
8〜18秒  AI映像で当時の光景や仕組みを再現
18〜23秒 予想外の失敗・意味の変化を回収
23〜27秒 短いツッコミ＋CTA
```

感情曲線:

```text
危機・緊張 → すごい・納得 → 失敗・意外 → 安心して笑う
```

## 投稿配分案

- グルメ: 週1本
- 天才の残念ヒストリー: 週2本

同じFlow 8秒×2カット、Remotion、VOICEVOX、字幕、約25秒を維持し、主要変数を「題材」だけにする。

## 判定

公開72時間で比較する。

- 再生数
- 平均視聴率
- Shorts流入
- YouTube検索流入
- 反応（高評価、コメント、登録）

3本以上の同条件データが揃うまで、シリーズの全面継続・全面停止は決めない。

## 継続／停止／保留

- グルメ: **継続。ただし週1本へ縮小**
- 動画形式: **継続**
- 新シリーズ: **来週から試験開始**
- 飯シリーズへの一本化: **保留**
