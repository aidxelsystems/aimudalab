# 次のAIグルメ提案：島根・津和野「うずめ飯」

作成日: 2026-08-19  
目的: フック改善によって公開72時間10再生、挑戦目標100再生を狙う

## 結論

次作は、島根県石見地方・津和野の郷土料理「うずめ飯」を第一候補とする。

採用理由:

- `日本五大名飯`という強い数字・権威がある。
- 表面は白いご飯中心なのに、下にタイや野菜などの具が隠れている。
- `名飯なのに具がない？`で、矛盾と未解決の疑問を同時に作れる。
- スプーンで掘ると具が現れるため、Google Flowで気持ちいい映像変化を作りやすい。
- 質素倹約の時代に贅沢を悟られないため隠した、などの由来説があり、短い歴史とツッコミを両立できる。
- ゼリーフライで弱かった`驚かせてその場で完結`を、`驚き→疑問→映像で回収`へ改善できる。

- スプーンが掘り始める直前で止める。

- `日本五大名飯`を赤または金、`具がない？`を最大文字にする。


料理名、地域、疑問、Shorts表記を含み、答えはタイトルで明かさない。

## Google Flow 2カットの方向

### 1カット目：隠す工程

- 漆塗り風の椀へ、煮たタイ、豆腐、人参、しいたけ、里芋などを入れる。
- 上から白いご飯を置き、具を完全に隠す。
- 澄んだ出汁とわさびで、表面は質素に見せる。

### 2カット目：発見の瞬間

- スプーンが白いご飯をゆっくり割る。
- 下から色鮮やかな具と出汁が現れる。
- 湯気、照り、スプーンですくう接写で食欲を作る。

避けるもの:

- 生魚の刺身、寿司、カレー、チーズ、洋風スープ
- 具が最初から表面に露出した完成形
- 人の顔、文字、ロゴ、不自然な箸やスプーン
