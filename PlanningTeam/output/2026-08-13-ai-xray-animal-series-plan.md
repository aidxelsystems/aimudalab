# 100再生を狙う新企画「AI透視図鑑」 2026-08-13

## 結論

次の企画軸は、検索される動物雑学とAIエンタメを組み合わせた`AI透視図鑑`を推奨する。

シリーズの約束は、`知っている動物をAIで透視すると、知らない姿が出てくる。`

検索で疑問への答えを届け、Shortsフィードでは「見慣れた動物の常識が1秒で崩れる画」で止める。説明だけで終わらず、最後にその能力を人間社会へ移植したAI映像を1枚入れ、`AIのムダづかい`らしさを回復する。

## なぜこの企画か

- 珍獣名だけでなく、ペンギン・猫・タコなど母数の広い動物を入口にできる。
- `動物名＋足／心臓／ゴロゴロ／仕組み`という具体的な検索意図がある。
- X線、超拡大、能力の可視化は生成AIと相性がよい。
- 普通の雑学動画との差を、最後の`人間に移植したら`で作れる。
- 3択の読み上げ待ちを減らし、15〜21秒で知識と笑いを回収できる。

## 基本フォーマット（18〜21秒）

| 時間 | 内容 | 役割 |
|---|---|---|
| 0〜1秒 | 常識を壊す断言＋異常画像 | フィード停止 |
| 1〜4秒 | 答えを先に見せる | 待ち時間をなくす |
| 4〜10秒 | AI透視／超拡大で仕組みを可視化 | 納得感 |
| 10〜15秒 | 生き物にとっての利点 | 知識報酬 |
| 15〜19秒 | 人間に移植したAI映像 | 笑い・チャンネル独自性 |
| 19〜21秒 | 一言回収＋ループ | 記憶・再視聴 |

クイズ要素は完全に捨てず、`どこまで足だと思う？`など1秒以内の問いに縮める。A・B・Cの読み上げ待ちは次の比較実験では使わない。

## 候補ランキング

### 1位：ペンギンの足は、体の中まで長い

- 検索候補: `ペンギン 足`、`足長い`、`足の長さ`、`足の骨`、`足 折りたたみ`
- 0秒: `衝撃。ペンギン、足を隠してます。`
- 検索タイトル案: `ペンギンの足は本当は長い？骨格をAIで透視 #Shorts`
- 知識: 長い足の骨の多くが胴体内に隠れ、膝を曲げたような姿勢になっている。
- 理由: 水中で抵抗を減らす流線形への適応として説明する。
- AIエンタメ: 人間がペンギンと同じ姿勢を本気で再現し、街中を全員ヨチヨチ歩く。
- 最後: `短足じゃない。隠し足だった。`
- 評価: 需要5 / 画5 / 意外性5 / AI独自性5 / 正確性4 = 24/25

### 2位：タコの心臓は3つ

- 検索候補: `タコ 心臓`、`心臓3つ`、`心臓 3つ なぜ`
- 0秒: `このタコ、心臓が3つあります。`
- 検索タイトル案: `タコの心臓はなぜ3つ？体内をAIで透視 #Shorts`
- 知識: 全身へ送る心臓と、えらへ血液を送る2つの心臓。
- AIエンタメ: 心臓3基を積んだ会社員が会議・残業・飲み会を同時処理するが、全部疲れる。
- 最後: `心臓3つでも、月曜は無理。`
- 評価: 需要5 / 画5 / 意外性5 / AI独自性5 / 正確性3 = 23/25

### 3位：猫のゴロゴロ音はどこから出る？

- 検索候補: `猫 ゴロゴロ`、`なぜ`、`仕組み`、`効果`、`爆音`
- 0秒: `猫の中にエンジンはありません。`
- 検索タイトル案: `猫のゴロゴロ音はどこから？仕組みをAIで可視化 #Shorts`
- 知識: 中枢神経からの信号と、呼吸に伴う喉頭の筋肉・声帯付近の振動として説明。
- AIエンタメ: 猫のゴロゴロを巨大スピーカーへ接続し、街全体が眠る。
- 最後: `エンジンじゃない。でも人間は停止する。`
- 評価: 需要5 / 画4 / 意外性4 / AI独自性5 / 正確性4 = 22/25

### 4位：ヤモリは接着剤なしで壁に張りつく

- 検索候補: `ヤモリ 壁`、`壁に張り付く`、`理由`、`なぜ`
- 0秒: `吸盤でも、接着剤でもない。`
- 検索タイトル案: `ヤモリはなぜ壁に落ちない？足裏をAIで超拡大 #Shorts`
- 知識: 足裏の微細な毛と、その先のさらに細かな構造が表面へ密着する。
- AIエンタメ: ヤモリ足の会社員が天井の自席で会議する。
- 最後: `貼ってない。触れすぎている。`
- 評価: 需要4 / 画5 / 意外性4 / AI独自性5 / 正確性4 = 22/25

### 5位：カメレオンの色は「背景コピー」だけではない

- 検索候補: `カメレオン 色変わる`、`仕組み`、`理由`、`瞬間`
- 0秒: `背景に合わせてるだけ、ではありません。`
- 検索タイトル案: `カメレオンはなぜ色が変わる？皮膚をAIで透視 #Shorts`
- 知識: 皮膚中の構造と光の反射、体温や状態・コミュニケーションを扱う。
- AIエンタメ: 会議中の感情が全社員の服の色に即反映される。
- 最後: `空気を読むより、色に出る。`
- 評価: 需要4 / 画5 / 意外性4 / AI独自性5 / 正確性3 = 21/25

## 推奨する最初の3本

1. ペンギンの隠れた長い足
2. タコの3つの心臓
3. 猫のゴロゴロ音

`見た目の逆転 → 体内の数 → 身近な音`と変化させながら、同じ`AI透視図鑑`の型を維持する。

## ペンギン編の具体構成

1. 0秒: 普通のペンギン＋`衝撃。足を隠してます。`
2. 1〜3秒: `短足に見えるけど…`
3. 3〜7秒: AI透視で骨格を重ね、胴体内の脚を一気に表示。
4. 7〜11秒: `長い足の骨が体の中に隠れている。`
5. 11〜15秒: `水の抵抗を減らす流線形。泳げば速い。`
6. 15〜19秒: 人間が同じ姿勢で通勤するAI映像。
7. 19〜21秒: `短足じゃない。隠し足だった。`から冒頭へループ。

### 冒頭画面

- 上小: `ペンギンの足`
- 中央大: `実は長い!?`
- 下赤: `体の中に隠してます`
- ペンギンの全身と、半透明で見える脚骨格を同時表示。

## 100再生への流入設計

100再生を保証する企画はないため、検索とフィードの役割を分けて設計する。

### 検索

- タイトル先頭を`ペンギンの足`とする。
- 概要欄冒頭に`ペンギンの足は短く見えますが、長い足の骨が体の中に隠れています`と自然に書く。
- `ペンギン 足長い`、`ペンギン 足の骨`、`ペンギン 膝`をタグ候補へ入れる。
- 動画内音声にも`ペンギンの足`を入れ、メタデータと内容を一致させる。

### Shortsフィード

- クイズの説明から始めず、0秒で答えに近い異常事実を出す。
- 最初のフレームから完成した大文字を表示する。
- 21秒以内、6〜7場面、1場面1メッセージ。
- 15秒付近にAI人間再現を置き、知識だけで終わらせない。
- 最後の画を冒頭の普通のペンギンへ戻せる構図にする。

## 成功判定

### 24時間

- 公開再生5以上。
- Studioの`フィードに表示`が直近クイズ以上。
- `視聴を選択した割合`が65%以上を目標とする。

### 72時間

- Shortsフィード再生5以上。
- 平均再生率85%以上を目標とする。
- 検索流入1以上。

### 7日間

- 最低30再生。
- 挑戦目標100再生。
- 検索流入20、Shortsフィード50、その他・回遊30を目安とするが、配分は結果として測定し、達成条件にはしない。
