# 新番組案「AIのウソを見抜け！」2026-08-09

## 結論

新しい中心フォーマットは `3つのうち1つはAIのウソ` を推薦する。  
動物、発明、方言、地方あるある、都市伝説、世界の習慣を、同じ「真偽クイズ番組」として統合できる。  
感情の流れは `驚き→疑い→考える→正解発表→納得`。大喜利の創作力と、事実紹介の検索価値を両立する。

## 番組名候補

第1候補: `AIのウソを見抜け！`  
第2候補: `ガチ？AI？`  
第3候補: `世界の本当かよ研究所`

推奨するシリーズ表示:

`AIのウソを見抜け！ #01 変な動物編`

## 番組の約束

`信じられない3つを見せます。1つだけ、AIが作ったウソです。`

ムダくんが3案を出し、ガチくんが一次資料を確認して最後に判定する。

## 20～24秒構成

| 時間 | 内容 | 感情 |
|---|---|---|
| 0～1秒 | 3枚を一瞬で見せ「1匹だけAIです」 | 驚き |
| 1～5秒 | 候補A＋信じられない特徴 | 好奇心 |
| 5～9秒 | 候補B＋特徴 | 疑い |
| 9～13秒 | 候補C＋特徴 | 迷い |
| 13～16秒 | 3、2、1のカウント | 緊張 |
| 16～20秒 | AIのウソを消し、実在2件の根拠を一言 | 驚き・納得 |
| 20～23秒 | `見抜けた？ A・B・Cで回答` | 参加 |
| 23～24秒 | 冒頭3枚へ戻る | 再視聴 |

## 最初の3本

### 第1作: 世界の変な動物

タイトル案: `3匹のうち1匹は存在しません｜AIのウソを見抜け！`

- 市場需要と視覚的な強さが最大。
- 実在2匹は動物園・博物館・研究機関で確認する。
- 架空1匹は既存動物名・伝承生物・絶滅種と重ならないよう確認する。
- 正解発表で実在動物の最も意外な能力を1つ残す。

### 第2作: 世界のとんでもない発明

タイトル案: `3つのうち1つは存在しない発明です｜AIのウソを見抜け！`

- チャンネル名との一致が最も強い。
- 実在2件は特許、メーカー、博物館等の一次資料を確認する。
- 特許があるだけで製品化されたとは限らないため、`特許あり` と `実用品` を区別する。

### 第3作: 方言・地方あるある

タイトル案: `3つのうち1つはAIが作ったニセ方言｜○○県編`

- 地元視聴者が正解・補足・世代差をコメントしやすい。
- 実在2件は自治体・文化資料と複数の使用例で確認する。
- ニセ方言は地域や話者を嘲笑する内容にしない。

## 題材の優先順位

1. 面白動物: 最初の露出獲得
2. 発明: チャンネル独自性の確立
3. 方言: コメント・地域参加の獲得
4. 都市伝説: 信頼ができた後に `事実が1つ` 形式で導入
5. 世界の習慣: 文化的背景を説明できる尺と監修方法を整えてから導入

## 「感情＋なるほど」の設計

- 感情: 本当にいるのか、どれがウソかという驚きと緊張。
- なるほど: 正解発表時に、実在する理由・能力・由来を1つだけ説明。
- 笑い: AIのウソが無駄に精巧、または少しだけ変。
- 参加: 正解発表前にA・B・Cを選ばせ、最後に自己採点させる。

## 誤情報防止

- 動画内で正解を必ず明示し、ウソのまま終わらせない。
- タイトル・概要欄にもクイズであることを明記する。
- 実在情報の出典を企画書と概要欄に残す。
- AI画像には必要に応じて `AI再現`、架空候補には正解発表後 `AI創作` と表示する。
- 都市伝説は `事実`、`未確認`、`創作` の3区分で扱う。

## 成功条件

- 公開72時間でShortsフィード10再生以上。
- 平均再生率90%以上。クイズ再視聴で100%以上を上振れ目標とする。
- 3本合計でA・B・C回答コメント3件以上。
- 3本中1本が公開7日で30再生以上。上振れ目標100再生。
- 動物、発明、方言の中で最も反応が強い題材を、次の3本の中心にする。

## 制作方針

- 3本をまとめて作らず、まず動物編1本だけ制作する。
- 既存の上側テロップ、VOICEVOX、効果音、縦画面を維持する。
- タイトルカードではなく、0秒から3候補の最も強い顔・姿を見せる。
- ムダくん・ガチくんは画面を占有せず、声と判定スタンプから導入する。

## 次の作業

承認後、動物編について候補動物と一次資料を調査し、ProductionTeam向け企画書を確定する。ユーザー承認前は既存予約、`story.json`、動画を変更しない。
