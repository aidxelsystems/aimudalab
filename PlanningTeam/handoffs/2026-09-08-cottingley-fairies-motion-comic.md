# 本当にあったムダ漫画 第2作 制作引継ぎ

作成日: 2026-09-08 JST

episode: `motion-comic-cottingley-fairies-02`

状態: ユーザー企画承認済み / ProductionTeam制作設計待ち

お題: 1917年に少女たちが撮影した「コティングリー妖精写真」を、シャーロック・ホームズの作者アーサー・コナン・ドイルが本物だと信じ、広く紹介した実話。

採用理由: `名探偵を生んだ作家 × 妖精写真を信じる`という一文で分かる人物ギャップがある。エッフェル塔回の「普通の人と異なる思考」を引き継ぎながら、建造物売却詐欺の反復を避け、写真検証の緊張、検査をすり抜ける仕掛け、数十年後の告白まで段階的に進められる。

## ペルソナ

- 主対象: 34歳会社員の佐藤健太。通勤、休憩、就寝前にShortsを視聴する。
- 関心: ミステリー、詐欺、歴史上の失敗、人に話せる奇妙な実話。
- 前提知識: シャーロック・ホームズは知っているが、コナン・ドイルの思想や妖精事件は知らない。
- 視聴理由: AI映像ではなく、`論理的な名探偵を生んだ人物にも意外な盲点があった`という人間的な矛盾。
- 共有動機: 家族や同僚へ「ホームズの作者が妖精写真を信じた」と一文で話せる。
- 離脱要因: 固有名詞の連続、心霊主義の長い講義、写真技術の専門説明、冒頭で仕掛けを明かすこと。

狙う視聴者: 日本の25〜44歳を中心とする、専門家ではない雑学・ミステリー視聴者。年齢と人物像は企画仮説であり、Studio実績取得後に更新する。

市場シグナル: 妖精、古写真、シャーロック・ホームズという認知対象があり、`本物か偽物か`の未解決状態を最後まで保ちやすい。National Science and Media Museumは本件を著名な写真操作例として紹介し、コナン・ドイルの関与が事件を広い読者へ届けたとしている。

自チャンネル実績: 2026-09-06取得値では、公開24時間の比較可能な22本は中央値3回、上位25%点5.75回、上位10%点8.9回、最大11回。公開72時間の21本は中央値4回、上位25%点8回、上位10%点15回、最大21回。累積39本は中央値6回、最大39回。漫画第1作は2026-09-10公開予定で、同形式の公開実績はまだない。

今回変える1要素: 主人公を詐欺師から、名探偵を生んだ著名作家へ変更し、感情曲線を `犯罪の緊張→成功→再犯` から `いたずら→検証の緊張→検査突破→権威の信用→告白→皮肉` へ変える。

変えない要素: 38〜43秒、縦9:16、史実フック、AI歴史再現、VOICEVOXの話者役割、大きな上部見出し、Remotionによる画角・色・無音の感情演出、最後だけずんだもんのツッコミ、CTA統合、出典表示。

冒頭1秒の約束: `名探偵を生んだ男が、妖精を信じた。` 妖精写真風の画、コナン・ドイル、シャーロック・ホームズを想起させる探偵シルエットを同時に見せる。シリーズ名や1917年の説明を先に置かない。

## 推奨構成

| 時間 | 感情 | 内容 |
|---|---|---|
| 0〜3秒 | 驚き | 「これは実際にあった話」。ホームズの作者が妖精写真を信じたと提示。 |
| 3〜8秒 | 軽いいたずら | 少女たちが妖精の絵を切り抜き、帽子ピンで固定して撮影。仕掛けの全体はまだ見せない。 |
| 8〜12秒 | 常識とのギャップ | 普通の大人「子どものいたずらだろう」→間→ドイル「これは本物だ」。 |
| 12〜19秒 | 検証の緊張 | 新しいカメラと印を付けた写真乾板を渡し、追加写真を求める。 |
| 19〜24秒 | 一時的な信用 | 写真乾板そのものへの加工が見つからず、妖精の存在を信じる方向へ傾く。 |
| 24〜29秒 | 仕掛けの回収 | 「写真は加工していない。紙の妖精をそのまま撮ったから」。横視点で紙と帽子ピンを図解。 |
| 29〜34秒 | 権威による拡散 | ドイルが雑誌などで写真を紹介し、世界的な話題になる。 |
| 34〜39秒 | 遅い告白 | 60年以上後、作成者側が仕掛けを明かす。静かな間を取る。 |
| 39〜43秒 | ツッコミ | 「ホームズの作者、そこは見抜けないんかい！」。真相画面のままCTAを小さく統合。 |

必要カットの画の方向:

- 1917年の庭、紙の妖精制作、初回写真、ドイルの検討、新カメラの受け渡し、乾板確認、横から見た仕掛け、雑誌記事、老年期の告白を別画像で展開する。
- 博物館所蔵写真をそのまま複製せず、史実に基づく独自のAI再現画にする。
- コナン・ドイル、少女2人、妖精切り抜きの外見を参照画像で一貫させる。
- 直接記録のない台詞は「演出上の台詞」として扱い、引用符付きの史料発言に見せない。

避ける表現:

- 少女たちを悪質な犯罪者として描くこと。
- 「専門家全員が本物と認定した」などの過剰な一般化。
- 写真乾板への画像合成だったと誤解させること。
- ドイルを知性のない人物として嘲笑すること。
- 第五の写真の真偽を本編で断定すること。後年も当事者間で説明が一致しなかったため、本編は最初の写真群の紙の仕掛けに絞る。
- 史料写真、雑誌ページ、シャーロック・ホームズ映像作品の構図や意匠を無断で複製すること。
