# 本当にあったムダ漫画 第1作 制作引継ぎ

作成日: 2026-09-06 JST

episode: `motion-comic-eiffel-scam-01`

状態: researched / ユーザーの本編制作承認待ち

お題: エッフェル塔を解体用スクラップとして売る話を信じ込ませた、ヴィクター・ラスティグの詐欺

採用理由: 誰でも認識できる建造物と「売る」という不可能に見える行為が0秒で伝わり、金銭詐欺の緊張、成功、発覚、再実行の二段オチまで一事件で進められる。

狙う視聴者: 通勤、休憩、就寝前にShortsを見て、「人に話せる本当の変な話」を短時間で得たい日本の25〜44歳。年齢・性別は検証前の仮説であり、確定ターゲットではない。

市場シグナル: 実話漫画、史実雑学、キャラクター会話劇、短尺の失敗・詐欺話には既存需要がある。採用するのは0秒理解、因果進行、終盤報酬という構造であり、競合の台詞、構図、画像、キャラクターは模倣しない。

自チャンネル実績: 2026-09-06取得時点で39本・294再生・登録者2。公開72時間の比較可能な21本は中央値4回、最大21回。Shortsフィード流入は集計期間218再生中11回で、形式の良否を断定できる露出はない。

今回変える1要素: 従来のFlow映像中心から、5枚の独立画像をRemotionでコマ送り、ズーム、パン、衝撃演出する15〜18秒漫画へ変える。

変えない要素: 検証3本では画風、尺、上下一問字幕、話者の役割、CTA統合、公開時刻帯、計測方法を固定する。

冒頭1秒の約束: `エッフェル塔、売ります`。驚き顔、詐欺師、エッフェル塔、象徴的な鍵だけを見せ、札束と契約書は後のコマへ送る。

## 5コマ構成

| 時間 | 役割 | 画像と台詞の方向 |
|---|---|---|
| 0.0〜2.5秒 | 異常 | 塔を背に鍵を差し出す詐欺師と、画面の約3分の1を占める驚き顔。上部固定見出し`エッフェル塔、売ります`。 |
| 2.5〜5.5秒 | 信用 | 1925年パリの高級ホテルで、偽の政府文書を示す秘密会合。青山龍星が「政府関係者を装い」と事実を進める。 |
| 5.5〜9.0秒 | 成功 | 解体用スクラップの入札だと信じた買い手が契約・支払い。登場人物の短い台詞を1つだけ入れる。 |
| 9.0〜13.0秒 | 発覚 | 詐欺師が金銭を持って逃走し、買い手が塔を見上げて青ざめる。所有権移転ではなく詐欺だったと明示。 |
| 13.0〜18.0秒 | 二段オチ | 詐欺師が別の買い手へ同じ鍵を差し出す反復構図。ずんだもんが`詐欺、二周目あるんかい！`。CTAは同画面下へ小さく統合。 |

必要カットの画の方向:

- 5枚すべてを別画像にし、各コマで場所、動作、表情の最低1つを変える。
- 1920年代パリとして統一し、詐欺師と主要な買い手は参照画像で一貫させる。
- 画像へ文字を焼き込まず、字幕、文書の可読情報、CTAはRemotionで追加する。
- 上部は最大2行18字、下部は1情報8〜16字・最大2行。重要な顔と情報は右180px、下320pxを避ける。
- 青山龍星=speaker 13、登場人物=四国めたん等、ずんだもん=speaker 3で最後のみ。基本3声まで。

避ける表現:

- エッフェル塔の実際の所有権が移転したような断定。
- 被害者や史実にない台詞を、記録された発言のように見せること。
- 現代の服装、紙幣、電子機器、文字崩れ、余分な指、人物の顔の不一致。
- 冒頭への札束、買い手、契約書の詰め込み。
- 同一画像の5クロップ、止まった説明画面、独立した登録CTA、20秒超の追加解説。

公開後24時間の成功指標: Shortsとして分類され制限なしであることを確認し、公開再生10回以上を暫定目標とする。再生数にかかわらず、Shown in feed、視聴選択率、平均視聴率、流入元、反応を保存できれば診断は成立。

公開後7日間の成功指標: 公開72時間30回以上を最低線、7日で100回以上を成功、500回以上を強い成功とする。補助指標はShortsフィード比率30%以上、平均視聴率80%以上、反応1件以上。

## 事実確認

一次の制作根拠として以下を保存している。公開前に1925年、政府関係者の偽装、ホテルでの会合、解体用スクラップ、金銭詐取、再度の試みの確度を追加確認する。

- [Smithsonian Magazine: The Man Who Sold the Eiffel Tower. Twice.](https://www.smithsonianmag.com/history/man-who-sold-eiffel-tower-twice-180958370/)

AI画像は歴史再現であり証拠写真ではない。概要欄でAI再現と出典を明示する。

## 品質ゲート

1. 5枚の独立画像、人物一貫性、焼き込み文字なし。
2. 無音0.5秒で対象、2秒で異常、18秒で詐欺とオチが理解できる。
3. 字幕安全域と実測音声同期、漢字の読みを試聴する。
4. TypeScript、完成MP4、フック・支払い・発覚・オチの代表フレームを確認する。
5. H.264 / AAC / 1080×1920 / 30fps / 48kHz、約-16 LUFS、True Peak -1〜-1.5 dBTP。
6. 出典、AI再現表示、誤認防止、使用素材の権利を確認する。

制作開始前に`npm run sync:start`を実行し、Project StatusとProduction Boardでownerを確保してpushする。YouTube投稿はこの引継ぎに含まず、別途ユーザーの明示依頼を必要とする。
