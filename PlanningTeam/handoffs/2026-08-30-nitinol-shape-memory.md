# ProductionTeam Handoff｜形状記憶合金ニチノール

作成日: 2026-08-30 JST

## 企画結論

お題: ぐにゃぐにゃに曲げた金属が、お湯で元の形へ戻る「形状記憶合金ニチノール」

採用理由: 自チャンネルで初速が相対的に強い「プリンス・ルパートの滴」の、同じ物体が条件で逆の挙動を示す構造を再現できる。さらに、直近の過冷却で見えた「結果先出し後の離脱」に対し、曲げる→復元→別の形で再復元という第二の映像報酬を中盤に置ける。

状態: PlanningTeam採用済み。ProductionTeamが史実・物性表現を一次資料で再確認後、台本と素材を確定する。

## 視聴者と市場

狙う視聴者: 金属、変形、満足映像、NASA技術、身近な科学実験が好きで、30秒で驚きと一つの納得を得たい視聴者。

市場シグナル: 2026-08-29のPlanningTeam調査で、同現象を扱う海外Shortsに約373万再生と約104万再生の複数事例を確認。NASA STEMにも湯で形状回復を観察する教材がある。市場事例は需要の存在を示すが、自チャンネルでの成功は保証しない。

自チャンネル実績:

- プリンス・ルパートの滴: 公開約24時間で11再生。科学シリーズの初速最多。
- 過冷却: 公開約72時間で21再生。一方、取得済み10再生の平均視聴率は44.97%。
- コーラ噴水: 6再生と発見が弱いが、平均視聴率は70.77%。
- Analytics対象期間の流入はYouTube検索135回（69.2%）、Shorts 13回（6.7%）。
- 高評価、コメント、共有、登録増は小標本上ほぼ発生していない。

## 実験設計

今回変える1要素: 8〜15秒に第二の実験カットを置く。最初の簡単なワイヤ復元の後、異なる記憶形状が回復する完成画を再度見せる。

変えない要素:

- 25〜32秒
- 0秒から異常現象の完成画
- 1秒以内に未解決の問い
- 青山龍星の説明とずんだもんのツッコミ
- 上見出し、下字幕、AI再現表示
- 仕組みは一枚図解・一概念に絞る
- 応用を一つに絞る
- 最後に短いツッコミ
- 19時公開

比較対象: 過冷却。結果先出しと科学図解を維持し、中盤の第二変化の有無を主な差とする。

## 制作契約

冒頭1秒の約束: `この金属、お湯で記憶が戻ります。`

冒頭映像: ぐにゃぐにゃの金属線を熱水へ入れた直後、一気に明確な形へ戻り始める接写。水面、金属、復元運動の三点だけに集中させる。

推奨構成:

| 区間 | 役割 | 映像の方向 |
|---|---|---|
| 0〜3秒 | 結果先出し | つぶしたニチノール線が湯の中で一気に元の形へ戻る。 |
| 3〜7秒 | 条件の対比 | 常温では曲がったまま、加熱で動き出す左右比較。 |
| 7〜11秒 | 名称回収 | `形状記憶合金 ニチノール`を大表示。 |
| 11〜15秒 | 第二の映像報酬 | 別の簡単な記憶形状が、加熱で一気に完成する。 |
| 15〜20秒 | 一枚図解 | 低温側と高温側の組織状態が切り替わり、記憶された形へ戻ることを簡略図で示す。 |
| 20〜26秒 | 応用 | NASAが紹介する、形状記憶合金による航空機部品の変形応用をAIイメージで一つだけ示す。 |
| 26〜30秒 | オチ | 復元した金属を背景に、ツッコミへ集中。 |

必要カットの画の方向:

1. 熱水中で歪んだ線が回復するマクロ。
2. 常温と加熱の左右比較。
3. 名称を示す整然とした金属サンプル。
4. 第二の形状回復。冒頭と違う輪郭と画角にする。
5. 組織状態の切り替わりを示すRemotion図解。
6. 航空機部品が滑らかに変形するAI応用イメージ。
7. 復元後の金属とオチのクリーンな最終画面。

確定オチ: `金属のほうが、昨日のこと覚えとる！`

コメントCTA候補: `形を覚えてほしい物、何ですか？`

## 避ける表現

- すべてのニチノールが同じ温度で復元すると一般化しない。
- 温度だけでなく、合金組成、熱処理、加工履歴などで挙動が変わるため、特定の復元温度を全体の固定値として断定しない。
- 「金属が本当に考えて記憶する」と誤解させない。
- 単純に溶けて戻る現象と表現しない。
- NASAがニチノールを発明したと表現しない。
- 航空機の描写を「広く実用化済み」と断定せず、研究・試験・技術実証の範囲を一次資料で確認する。
- 熱水による火傷の恐れがあるため、無防備な家庭実験を促さない。
- AI映像を実際の実験記録、NASA公式映像、実在製品の実写として扱わない。
