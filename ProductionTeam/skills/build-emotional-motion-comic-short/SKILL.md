# 感情が動く史実モーションコミック

## 目的

事実の列挙ではなく、主人公の発想と視聴者の感情を追わせる。Remotionの動き、色、画角、BGM、無音、VOICEVOXの間を一つの感情曲線として設計する。

## 基本の感情曲線

題材に合わせて次の順を基準にする。

1. 実話フック: 事実であること、人物、異常な出来事を最初の2秒以内に同時提示する。
2. 常識: 普通の人ならどう考えるかを短く示す。
3. 異常な発想: 主人公だけが別の結論へ飛ぶ。最初の強いピークにする。
4. 準備と実行: 手順を並べすぎず、危うい一手と相手の反応を交互に見せる。
5. 成功: 相手の決断を台詞で聞かせ、その後に支払いや成立を説明する。
6. 安堵: 成功直後は最低0.5秒、画面と音を落ち着かせる。
7. 静寂と気づき: 短い独白を十分に聞かせ、次の説明と重ねない。
8. 再転換: 同じ手を繰り返す異常さを、巻き戻しや反復で一瞬に理解させる。
9. ツッコミ: 結末を要約せず、視聴者が感じた矛盾を代弁する。

## 台詞と間の設計

- 表示文と読み上げ文を分ける。文字数ではなく、生成済みWAVの実時間を計測してフレームを決める。
- 前の音声の終了フレームを基準に次の音声を置く。ナレーション、人物台詞、ツッコミを重ねない。
- 説明から異常な発想まで `0.25–0.40秒` 空ける。
- 実行説明から買い手の決断まで `0.70–1.00秒` 空け、緊張を保つ。
- 買い手の決断から成立説明まで `0.55–0.75秒` 空け、決断を視聴者に飲み込ませる。
- 逃亡・成功説明から主人公の独白まで `0.40–0.60秒` 空ける。
- 独白から理由説明まで `0.35–0.50秒` 空ける。
- 助詞や接続語は因果に合わせる。「ところが」は逆接、「そこで」は発想を実行へ移す時に使う。
- 読み間違いが起きる語はVOICEVOX用テキストだけ平仮名にする。画面字幕は通常表記を保つ。

## 事実と判断過程の語り方

- 実話回は出来事だけでなく、主役が `何を知った→どう確かめた→何を根拠に判断した→何を見落とした` の順で追う。
- 記録された判断材料と、制作側が推測した感情を混ぜない。本人の著作・書簡・同時代資料で確認できない内心は断定しない。
- 接続語を省略しすぎない。`最初は / そこで / しかし / さらに / その結果 / ところが / なぜなら / そして`を因果に合わせて使い、音だけでも話がつながる文章にする。
- 各ナレーションは「前文を受ける接続」と「新しく分かった一情報」を持たせる。字幕を見なくても因果が理解できるか音声だけで確認する。
- 主役を単純に愚かだと処理せず、その時点では合理的に見えた根拠を先に示してから、見落としを回収する。
- 現代からの後知恵だけで笑わない。ツッコミは人物全体ではなく、判断の皮肉や一点の盲点へ向ける。

## Remotionの感情演出

- 緊張: 寒色寄り、狭いクロップ、微細な手ぶれ、暗い周辺減光、BGMを低く保つ。
- 異常な発想: 急接近、短い白フラッシュ、決め音、必要なら一瞬のBGM停止。
- 成功: 金色の単発フラッシュまたは衝撃を一度だけ使う。
- 安堵: 暖色へ戻し、引き画にし、動きと音量を落とす。次の展開を急がない。
- 気づき: ほぼ無音にして短い独白を中央に置く。
- 再転換: 既出映像の高速巻き戻し、同じ小道具の再登場、硬いカットで反復を見せる。
- ツッコミ: 中央の大きな袋文字と一度の衝撃で締める。強い画面振動は全編3回以内に絞る。
- BGMはナレーション中にダッキングし、無音区間を演出として残す。映像だけに感情表現を任せない。

## 制作手順

1. 史実の時系列と、視聴者に追わせる主人公の思考を分けて書く。
2. 感情曲線ごとにシーン、字幕、音声、BGM、SE、色、カメラを表にする。
3. VOICEVOX音声を生成し、各WAVの実時間を測る。
4. 音声終了後の無音を先に確保し、その後にRemotionのシーン境界を決める。
5. 強い演出は異常な発想、成功、最終ツッコミへ集中させる。
6. 代表フレームと音声区間表を確認してから最終レンダーする。

## QC

- 全音声が途中で切れず、重要台詞の前後に意図した無音がある。
- 成功直後に安堵があり、すぐ次の説明へ流れていない。
- 再転換が字幕を読まなくても反復として理解できる。
- 冒頭2秒、異常な発想、成功、静寂、ツッコミの代表フレームを確認する。
- 1080×1920、30fps、映像・音声codec、ラウドネス、デコードを確認する。
- 史実出典、AI再現表示、演出上の台詞である旨を概要欄または画面に記載する。
- YouTube投稿はユーザーの明示的な依頼がある場合だけ行う。
