# AIのムダづかい モーションコミック制作仕様

更新日: 2026-09-06 JST

## 目的

AI画像4〜5枚とRemotionだけで、無音でも意味が伝わり、最後まで因果を追いたくなる15〜18秒の縦型漫画を制作する。

画風は `ProductionTeam/output/style-samples/2026-09-06-motion-comic-hook-eiffel-v1.png` のセミリアルWebtoon調を基準とする。

## 基本原則

- 4コマを同時に並べない。1080×1920の画面全体を1コマとして順番に見せる。
- 1コマにつき、人物の動作、表情、場所、事実のうち一つを必ず前進させる。
- 1コマに一つのセリフ、一つの視覚情報だけを置く。
- 音声を消しても、問い、因果、オチが理解できる字幕にする。
- ナレーション全文を字幕化せず、意味を保った短文へ圧縮する。
- 最終結果は冒頭で全部見せず、途中状態だけを見せる。

## 18秒のコマ構成

| 時間 | コマ | 役割 | 画面 |
|---|---|---|---|
| 0.0〜2.5秒 | 1 | 異常・危機 | 主人公の大きな顔と、事件の途中状態。上部に一つの問いを固定する。 |
| 2.5〜5.5秒 | 2 | 起 | 誰が、何を始めたか。短いセリフを一つだけ表示する。 |
| 5.5〜9.0秒 | 3 | 承 | 成功しそうに見える場面。前コマより対象を大きく、近く、危険にする。 |
| 9.0〜13.0秒 | 4 | 転 | 本当の事実または失敗を公開する。数字や証拠を画像上で可視化する。 |
| 13.0〜17.0秒 | 5 | 結 | 最大の表情とツッコミ。最終画像のまま小さくCTAを添える。 |
| 17.0〜18.0秒 | ループ | 再視聴 | 最終コマを冒頭の構図へ寄せ、自然に0秒へ戻す。 |

## 画面レイアウト

```text
┌──────────────────┐  y=0
│ 上端安全域 0〜160px             │
│                                  │
│  固定の問い／フック              │  y=170〜410px
│  最大2行・中央揃え               │
│                                  │
│       顔・主役・事件              │  y=430〜1320px
│       画面の中心                  │
│                                  │
│  セリフ字幕                       │  y=1330〜1570px
│  最大2行・中央揃え               │
│                                  │
│ Shorts UI安全域                  │  y=1600〜1920px
└──────────────────┘
```

- 右端180pxには、重要な文字、顔、証拠を置かない。
- 下端320pxには、セリフやオチを置かない。
- 上部の問いは画像生成せず、Remotionで重ねる。
- 人物の目と口は、上部見出しと重ならない高さへ置く。

## 上部フック字幕

- 位置: `top: 170〜220px`を基準に、2行時も下端410px以内。
- 横幅: 最大900px。
- 文字サイズ: 84〜104px。短い決め語は112pxまで。
- 行数: 最大2行。
- 文字数: 1行7〜12文字を目安に、全体18文字以内。
- 書体: 太い角ゴシック、`font-weight: 900`。
- 表現: 白または黄色の塗り、黒10〜14pxの袋文字、重要語だけ赤または水色。
- 表示: 0秒から読める。文字を一文字ずつ出すタイプライター演出は禁止。
- シリーズ名は主字幕にせず、必要なら小さなバッジにする。

例:

```text
この男、
塔を売りました
```

## セリフ字幕

- 位置: `top: 1330〜1400px`を基準に、下端1570px以内。
- 横幅: 最大860px。左右各110px以上空ける。
- 文字サイズ: 56〜68px。
- 行数: 最大2行。
- 一度に表示する文字数: 8〜16文字。長くても22文字以内。
- 行間: 0.95〜1.08。
- 白文字＋黒8〜10pxの袋文字を基本にする。
- 男声は水色、女声は黄色の短い話者マークまたは下線で区別する。名前ラベルは原則表示しない。
- 重要語を一語だけ黄色または赤にする。全文の多色化は禁止。
- 音声より0.10〜0.18秒早く表示し、読み終わりから0.10秒残す。
- 文章単位で切り替える。単語ごとの高速点滅は使わない。

## 吹き出しの扱い

- 通常会話は下部字幕を使用する。
- 吹き出しは、登場人物が相手へ直接話す一言だけに限定する。
- 1画面に吹き出しは一つまで。
- 吹き出し内は12文字以内、最大2行。
- 顔、手、小道具、事件の中心を隠さない。
- ナレーション字幕と吹き出しを同時に出さない。

## VOICEVOX配役

- 青山龍星（speaker 13）: 全話共通の基本ナレーション。事実、時代、状況を短く伝える。
- ずんだもん（speaker 3）: 最後のツッコミだけ。途中の説明には使わない。
- No.7 アナウンス（speaker 30）: ニュース、公式発表、館内放送。
- 四国めたん ノーマル（speaker 2）: 大人の女性、依頼人、案内役。
- 玄野武宏 ノーマル（speaker 11）: 男性の登場人物、職人、会社員。
- 冥鳴ひまり ノーマル（speaker 14）: 怪談、秘密、落ち着いた女性の語り。
- WhiteCUL（speaker 23〜26）: 冷静な人物から大きな感情落差まで必要な場面。
- 中国うさぎ おどろき（speaker 62）: 驚きが物語上必要な一言だけ。

1話の基本人数は、青山龍星＋登場人物1名＋最後のずんだもんまで。異なる声を増やすこと自体を目的にせず、人物の役割が一瞬で分かる場合だけ追加する。

## コマ切替とRemotion演出

- コマ1: 6〜8フレームで顔へパンチズーム。問いは2〜3フレームで着地する。
- コマ2: 白いコマ枠を使った横スライド。切替は5〜7フレーム。
- コマ3: 前景1.08倍、背景1.02倍の疑似パララックス。
- コマ4: 証拠、数字、対象物をマスクで公開。公開直前に2〜3フレーム止める。
- コマ5: ツッコミと同時に軽い振動、色フラッシュ、105〜112%のズーム。
- トランジション中も完全な黒画面を作らない。
- 漫画の集中線、コマ枠、紙の質感は補助とし、毎秒動かし続けない。

## オチとCTA

- オチは画面中央寄り、文字サイズ88〜118px、最大2行。
- オチの背後には40〜55%の半透明黒帯を敷く。
- オチ表示中も人物の表情または事件の結果を残す。
- `チャンネル登録もよろしく`は36〜44pxで、オチの下へ0.5〜1.0秒だけ添える。
- CTAだけの独立画面は禁止する。

## 無音チェック

完成前に音声を消し、次を確認する。

1. 0.5秒以内に、誰または何の話か分かる。
2. 2秒以内に、何が異常か分かる。
3. 各コマを1秒停止しても、前コマから何が変わったか分かる。
4. セリフを読まなくても人物の感情が分かる。
5. 18秒以内に、事実とツッコミの両方が理解できる。

## 初回検証で固定するもの

- 同じ画風。
- 同じ字幕位置と文字サイズ。
- 同じ男女音声。
- 同じ15〜18秒の尺。
- 同じ5コマ構成。
- 同じ投稿時刻。

3本の間で変えるのは題材だけとし、字幕、速度、CTAを同時に変更しない。
