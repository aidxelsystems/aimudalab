# 「ムダくん、整いました！」なぞかけショート仕様

## 1. シリーズ概要

AI画像となぞかけを組み合わせ、言葉の共通点を視覚的に回収するショート動画シリーズ。

- 仮シリーズ名：`ムダくん、整いました！`
- サブ表記：`画像でAIなぞかけ`
- 標準尺：50〜58秒
- 標準問題数：3問
- 画面：縦型 1080×1920、30fps
- 主役：ムダくん、ガチくん
- 基本価値：言葉の「うまさ」、画像の「違和感」、2人の「掛け合い」を一度に見せる

## 2. 基本フォーマット

なぞかけの正式な言い回しは次の形とする。

```text
お題「〇〇」

整いました！

〇〇とかけまして、
〇〇と解きます。

その心は……

どちらも〇〇でしょう！

わー！
```

表記は「説く」ではなく「解く」を使用する。

## 3. 1本の標準構成

```text
0:00-0:02  冒頭フック
0:02-0:15  第1問：正統派
0:15-0:29  第2問：画像ボケ
0:29-0:46  第3問：スベり→回収
0:46-0:53  本日の判定
0:53-0:58  コメント誘導
```

3問すべてを同じテンポ、同じ画面、同じ決め方にしない。

## 4. 3問の役割

### 第1問：正統派

- 誰でも理解できる同音異義語や二重の意味を使う。
- シリーズのルールを視聴者に理解させる。
- 答えは説明なしでも通じる短さを優先する。
- 目標感情：`なるほど`

### 第2問：画像ボケ

- 2つの題材をAI画像で合体、置換、巨大化、擬人化する。
- 「その心は」の直後に約0.6秒、画像だけを見せる。
- 視聴者が一瞬「何これ？」と思ってから、言葉で回収する。
- 目標感情：`絵がどうかしている`

### 第3問：スベり→回収

- ムダくんが強引または弱いなぞかけを出す。
- 答えを読み切った後に短い無音またはチーンを入れる。
- ガチくんの一言を本当のオチにする。
- 必要に応じてガチくんが良い答えを出して回収する。
- 目標感情：`整ってない`→`掛け合いで笑う`

## 5. キャラクターの役割

### ムダくん

- 勢いよく「整いました！」と言う。
- 正統派、強引なダジャレ、思いつき担当。
- スベっても本人だけは満足している。
- 画像を無駄に壮大にする。

### ガチくん

- お題提示、聞き役、採点、ツッコミ担当。
- なぞかけの意味が伝わらない場合だけ短く補助する。
- 長い解説は避け、1フレーズで落とす。
- 決めツッコミ：`整ってない！`

### AI

- 2つの題材を合体した画像を生成する存在。
- 言葉を字面どおり解釈し、過剰な画像を出してよい。
- 画面内にAI本人を毎回登場させる必要はない。

## 6. 視覚設計

### 基本画面

- 左：かける題材A
- 右：解く題材B
- 中央：共通語または答え
- 上部：現在のお題
- 下部：字幕。ただし主役の顔や共通点を隠さない

### 出題時

2枚の画像を左右に見せる。答えの文字はまだ出さない。

```text
┌────────┬────────┐
│   題材A    │   題材B    │
└────────┴────────┘
        共通点は？
```

### 答えの回収

- 共通する言葉を中央へ大きく表示する。
- 題材Aと題材Bの該当箇所を同じ色で強調する。
- 答えの瞬間に、別々だった2枚を合体画像へ切り替えてもよい。
- 生成画像内の小さな日本語に依存しない。正確な文字はRemotion側で重ねる。

### 画像先行ボケ

```text
異常な画像を表示
↓ 0.55〜0.75秒
「その心は」
↓
答え、字幕、音声
↓
ガチくんのツッコミ
```

1枚につき、視覚的な異常点は1つに絞る。

## 7. 笑いのパターン

各動画では、最低3種類の笑いを使う。

| パターン | 内容 |
|---|---|
| 同音異義語 | 「AI」と「愛」のように音を重ねる |
| 二重の意味 | 「行列」など、異なる文脈で同じ語を使う |
| 画像の直訳 | 比喩や共通語を物理的な画像にする |
| ギャップ | 小さな答えを映画級の画像で見せる |
| スベり | あえて弱い答えを出し、間とツッコミで笑わせる |
| 裏切り | 予想した答えとは別の共通点を出す |
| 三段落ち | 3問目だけ答えや画像のカテゴリを変える |
| 視聴者参加 | 最後の「その心」をコメントで募集する |

同じ音だけを探した強引なダジャレを3問続けない。

## 8. テンポと音

- `整いました！`：小さな太鼓、木魚、またはチーン
- 題材A／題材Bの表示：左右から短くポップイン
- `その心は……`：BGMを一瞬絞り、0.3〜0.6秒の間
- 正解：和太鼓、拍手、短い歓声
- スベり：読み終わってからチーン。字幕表示と同時に鳴らさない
- ツッコミ：セリフを理解できる間を置いてから鋭いSE

同じSEを3問連続で使わない。

## 9. 字幕ルール

- 「〇〇とかけまして」は1〜2行。
- 「〇〇と解きます」は1〜2行。
- 「その心は」は単独表示。
- 答えは2行以内を基本とし、共通語を最後の行へ置く。
- 1行8〜15文字程度を目安に、意味のまとまりで改行する。
- 助詞だけを次行へ送らない。

例：

```text
どちらも
「あい」が必要でしょう！
```

## 10. なぞかけ品質基準

以下をすべて満たしたものを採用する。

1. 題材Aと題材Bの両方に、同じ語または意味が自然に成立する。
2. 答えを音声だけで聞いて理解できる。
3. 説明が必要な場合も、ガチくんの一言で済む。
4. 2つの題材を別々または合体画像として描ける。
5. スマートフォンで約1秒見れば、2つの題材を識別できる。
6. 前後の問題と、語、画角、背景、笑いの仕組みが重複しない。
7. 誰かを傷つける属性ネタ、実在人物への中傷、意味のない下品さを避ける。

## 11. 不採用基準

- 音が少し似ているだけで、意味上の共通点がない。
- 答えを理解するために長い専門解説が必要。
- 画像にすると題材Aと題材Bの区別がつかない。
- 正確な日本語看板を画像生成に任せないと成立しない。
- 3問とも同じ語尾、同じ左右分割、同じSEになる。
- ムダくんのスベりを、意図しない低品質なぞかけと混同している。

## 12. 視聴者参加回

3〜4本に1回は、第3問の答えを公開せず視聴者へ渡す。

```text
お題「〇〇」

〇〇とかけまして、
〇〇と解きます。

その心は？

あなたなら、
どう整えますか？
```

次回冒頭でコメント回答を1件紹介し、その後に通常の3問へ進む。

## 14. 完了チェック

- 全体が50〜58秒に収まっている。
- 3問の笑いの仕組みが異なる。
- 第1問は説明なしで理解できる。
- 第2問は画像だけでも異常点が見える。
- 第3問はツッコミまたは回収まで含めてオチになっている。
- 共通語を強調する正確な字幕がある。
- 下部字幕で重要な顔や物体を隠していない。
- 冒頭2秒で「なぞかけ動画」と分かる。
- 最後に答えやお題をコメントしやすい問いがある。
