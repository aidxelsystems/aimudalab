# エアロゲル 入力素材QC

確認日: 2026-08-27 JST

## 判定

**採用可。再生成は不要。**

両カットとも、Shortsで重要な一目理解、縦画面の構図、形状の安定、字幕安全域を満たしている。720×1280から1080×1920への1.5倍拡大は必要だが、代表フレームをLanczos拡大して確認した限り、主役の輪郭と色差は維持できている。

AI超解像で過度に細部を作り足す必要はない。編集時は高品質な拡大とごく弱いシャープ処理に留め、YouTubeへは完成版を1080×1920で出力する。

## Cut 1｜花と炎

- ファイル: `public/movie/Silica_aerogel_insulating_flower…_202608271730.mp4`
- 仕様: H.264 / 720×1280 / 24fps / 8.000秒 / 約1.22Mbps
- 判定: 合格

### 良い点

- 青い炎、半透明の板、無傷の花が同じ画面で一度に理解できる。
- 花のマゼンタ、炎の青、暗い背景の色差が強く、スクロール停止用の画として優秀。
- 花、板、支持具、バーナーの形状が開始・中盤・終盤で安定している。
- 上部に暗い余白があり、中央寄りの大きなフック文字を置ける。
- 4〜6.5秒付近は静止画だけでも矛盾が成立し、結果先出しに使える。

### 注意点と編集対応

- 半透明板がわずかに氷のようにも見える。5秒以内に `エアロゲル` と表示し、後続のNASA実物写真で補強する。
- 元映像はやや柔らかい。拡大時はLanczos相当の高品質スケーリングと弱いシャープ処理だけを使用する。
- 完成動画では4〜6.5秒を冒頭へ先出しし、その後に巻き戻してCut 1冒頭へ戻す。

## Cut 2｜彗星粒子コレクター

- ファイル: `public/movie/Space_probe_collecting_comet_dust_202608271731.mp4`
- 仕様: H.264 / 720×1280 / 24fps / 8.000秒 / 約2.30Mbps
- 判定: 条件付き合格

### 良い点

- コレクターパネルの格子と機体形状が安定している。
- 接写から宇宙船全体へ引くため、実験台から宇宙規模へ展開する役割が明確。
- 4.2秒付近に決定的な粒子接触があり、衝撃音と一回だけの画面揺れを同期できる。
- 黒い宇宙背景に字幕を置ける余白がある。

### 注意点と編集対応

- 粒子の一部が実際の彗星塵より大きな小石に見える。
- この映像を科学的証拠には使わず、画面へ `AIによる応用イメージ` と明記する。
- 粒子接触の直後にNASA/JPLのStardust公式画像へ切り替え、事実確認の役割を公式資料へ渡す。
- `粒子を壊さず捕獲` と `弾丸の最大6倍` は公式資料とRemotion図解で説明する。

## BGM｜Solid Smoke Launch

- ファイル: `public/BGM/Solid Smoke Launch.mp3`
- 仕様: MP3 / 48kHz / stereo / 約194kbps / 214.560秒
- 先頭32秒の解析: -15.62 LUFS / True Peak -0.03dBTP / LRA 7.0 LU
- 0.5秒以上・-45dB以下の無音: 検出なし
- 判定: 編集素材として採用可

### 音量対応

- 素材単体のTrue Peakが0dBに近いため、そのままナレーションへ重ねない。
- VOICEVOX下ではBGMを十分に下げ、公式資料と数字の場面ではさらに約3dBダッキングする。
- SEと音声を統合した完成版で、約-16 LUFS、True Peak -1.0〜-1.5dBTPへ最終調整する。
- 曲全体は約3分35秒あるため、完成動画の31〜32秒に合う区間を編集で選択する。

## 完成時の品質方針

- Composition: 1080×1920 / 30fps
- 元動画: 音声をミュート
- 拡大: 1.5倍、高品質スケーリング、弱いシャープのみ
- フレーム補間: 不要。24fps素材の緩やかな動きは30fpsタイムライン上でそのまま扱う。
- AI映像表示: `AI再現映像` または `AIによる応用イメージ`
- 証拠表示: NASA/JPL公式画像と出典を別表示
- 最大演出: Cut 2の粒子接触で一回だけ使用

## 結論

画質よりも構図と理解速度の強みが上回っている。720pを理由に再生成する必要はない。花カットは冒頭フックとして十分強く、宇宙カットは公式資料への橋渡しとして使えば、事実性と迫力を両立できる。
